# Image slots

The placeholders are the city illustrations from `dream_loadscreen`. Replace them with your own in-game screenshots (JPG, PNG, WebP or AVIF; `next/image` serves AVIF/WebP automatically). Then point to them in **Admin → Site settings → Home page**, or keep the same filenames.

| Slot | File | Size | Used on |
| --- | --- | --- | --- |
| Hero | `hero.svg` | 2560×1440 | Home hero (Ken Burns zoom). An optional muted loop video can be set in admin. |
| Life in the city | `feature-life.svg` | 1600×1200 | Home feature row 1 (skyline/sunset) |
| Choose your path | `feature-path.svg` | 1600×1200 | Home feature row 2 (police/EMS), 404 page |
| The community | `feature-community.svg` | 1600×1200 | Home feature row 3 (group shot) |
| Play | `play.svg` | 2560×1440 | `/queue` hero |
| Guide covers | `guides/*.svg` | 1600×1200 | Guide cards and guide headers |
| Open Graph | generated by `app/opengraph-image.tsx` | 1920×1080 | Link previews. To use a fixed image, add `app/opengraph-image.png` and delete the `.tsx`. |

Keep the important part of each image in the centre. Cards crop to 4:3 and 16:10, and the hero crops to the viewport.
