You can change most keybinds in **Settings → Key Bindings → FiveM** in the pause menu.

## Keybinds

| Key | Action |
| --- | --- |
| `kbd:M` | Phone |
| `kbd:Tab` | Inventory |
| `kbd:F1` | Radial menu |
| `kbd:L` | Lock / unlock vehicle |
| `kbd:B` | Seatbelt |
| `kbd:F6` | Vehicle controls |
| `kbd:N` | Push-to-talk (proximity) |
| `kbd:Z` | Change voice range |
| `kbd:X` | Hands up |
| `kbd:F8` | Console |

## Commands

| Command | What it does |
| --- | --- |
| `/me [action]` | Describe an action others can see |
| `/do [description]` | Describe the scene or answer a question |
| `/ooc [message]` | Brief out-of-character message (use sparingly) |
| `/report [message]` | Contact online staff |
| `/hud` | Customise your HUD layout |
| `/e [emote]` | Play an emote |

> [!TIP]
> `/me` and `/do` are for things the game can't show. "/me checks the glovebox" is good. "/me knocks him out" is powergaming.
